# معنى حكم قضائي باللغة الإنجليزية

في اللغة الإنجليزية، لا توجد كلمة واحدة تترجم بدقة وشاملة مصطلح “حكم قضائي” أو “قرار محكمة”. بدلاً من ذلك، هناك مجموعة من المصطلحات التي يعبر كل منها عن مرحلة، أو نوع، أو نتيجة محددة للعملية القضائية.

إليك تفصيل شامل للمصطلحات الأكثر أهمية:
## **مصطلحات تصف ناتج ومخرجات المحكمة**

**Judgment****الحكم النهائي / القرار الفاصل (في قضية مدنية)****Sentence****العقوبة / الحكم الجزائي****Verdict****قرار هيئة المحلفين****Ruling****قرار إجرائي / فصل في نقطة قانونية****Order****أمر قضائي****Decree****مرسوم / قرار محكمة غير تقليدية**

| المصطلح الإنجليزي | الترجمة الأدق | السياق والاستخدام |
| --- | --- | --- |
| هو القرار النهائي والفاصل الصادر عن المحكمة في القضايا المدنية (Civil Cases)، والذي يحدد حقوق والتزامات الأطراف (مثل دفع تعويضات، أو إبطال عقد). وهو القرار الذي يمكن استئنافه. |  |  |
| يُستخدم حصرياً في القضايا الجنائية/الجزائية (Criminal Cases) للإشارة إلى تحديد نوع ومقدار العقوبة المفروضة على المدان (مثل السجن، الغرامة، خدمة المجتمع، أو الإعدام). |  |  |
| هو القرار الذي تصدره هيئة المحلفين فقط (Jury) بخصوص براءة المتهم أو إدانته (Guilty أو Not Guilty) في نهاية المحاكمة، قبل أن يصدر القاضي الحكم النهائي (Judgment/Sentence). لا يطلق على قرار القاضي اسم Verdict. |  |  |
| هو قرار تصدره المحكمة في نقطة جزئية أو إجرائية أو تمهيدية أثناء سير القضية (سواء كانت مدنية أو جنائية)، مثل: قبول أو رفض الأدلة، أو الفصل في اعتراض محامٍ، أو تفسير نقطة قانونية محددة. لا يشترط أن يكون فاصلاً في الدعوى ككل. |  |  |
| هو أمر تصدره المحكمة يوجّه الأطراف للقيام بعمل ما أو الامتناع عنه (مثل أمر بالحضور، أمر تقييدي، أو أمر دفع مؤقت). يُستخدم في القضايا الإجرائية والمدنية والجنائية. |  |  |
| مصطلح تاريخي أو أقل شيوعاً، يُستخدم تقليدياً في قضايا محاكم الأسرة (مثل الطلاق – Divorce Decree)، أو للإشارة إلى قرارات صادرة عن محاكم إدارية أو شرعية أو كنسية، وليس بالضرورة عن محكمة مدنية أو جنائية نظامية. |  |  |

## **مصطلحات تصف الأسباب والنتائج**

### **1. Opinion (رأي المحكمة)**

- **السياق الأمريكي الشائع:** هو البيان المكتوب التفصيلي الذي تصدره المحكمة (خاصة المحاكم العليا ومحاكم الاستئناف) لشرح الأسباب القانونية والحجج التي استندت إليها في الوصول إلى Judgment (الحكم). وهو وثيقة أساسية في تطوير السوابق القضائية.
- **في الأنظمة الأخرى (مثل البريطاني):** قد يُستخدم للإشارة إلى المشورة أو المذكرة القانونية التي يقدمها المحامي (Counsel’s Opinion).
### **2. Disposition (نتيجة القضية/التصرف في الدعوى)**

- هذا المصطلح يُستخدم للإشارة إلى النتيجة النهائية الرسمية للقضية الجنائية.
- يشمل جميع الاحتمالات، مثل: الإدانة (Conviction)، البراءة (Acquittal)، رفض القضية (Dismissal)، أو التسوية.
## **مصطلحات أساسية تتعلق بنتيجة الحكم الجنائي**

هذه المصطلحات تصف الحالة النهائية للمتهم بعد النطق بالحكم:**Convicted****مُدان****Acquitted****مُبَرَّأ****Not Guilty****غير مذنب (نفي المسؤولية)****Charges Dismissed****رفض التهم / إسقاط التهم****Suspended Sentence****الحكم مع وقف التنفيذ**

| المصطلح الإنجليزي | الترجمة العربية | الشرح |
| --- | --- | --- |
| يعني أن الشخص قد صدر قرار حكم بإدانته رسمياً بارتكاب الجريمة المسندة إليه، وأنه ثبتت مسؤوليته الجنائية. |  |  |
| يعني أن الشخص قد صدر قرار حكم ببراءته من التهمة المنسوبة إليه بعد المحاكمة، مما ينهي التهمة بشكل دائم. القرار نفسه يسمى Acquittal. |  |  |
| هذا هو القرار الذي تصدره هيئة المحلفين أو القاضي. لا تعني بالضرورة البراءة، بل تعني أن الادعاء لم يثبت التهمة بما لا يدع مجالاً للشك. إذا كان الحكم النهائي هو “Not Guilty”، فإن النتيجة هي Acquittal. |  |  |
| قرار يتخذ من قبل المدعي العام أو القاضي قبل المحاكمة أو أثنائها بوقف النظر في التهم المسندة إلى الشخص لعدم كفاية الأدلة، أو لوجود خطأ إجرائي، أو لأن الفعل لا يشكل جريمة قانونية. |  |  |
| قرار بتأجيل أو تعليق تنفيذ العقوبة (السجن عادة) الصادرة على المدان، وغالباً ما يُمنح هذا القرار مقابل التزام المدان بفترة اختبار (Probation) أو خدمة مجتمع أو علاج. |  |  |
