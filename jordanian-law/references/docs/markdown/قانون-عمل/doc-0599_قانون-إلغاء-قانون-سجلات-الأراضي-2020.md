# قانون إلغاء قانون سجلات الأراضي رقم 3 لسنة 2020

### المادة 1

يسمى هذا القانون (قانون إلغاء قانون سجلات الأراضي لسنة 2020) ويعمل به من تاريخ نشره في الجريدة الرسمية.
