# مجموعة تقييم الاسترجاع (retrieval-v1)

`retrieval-v1.jsonl`: السطر الأول ترويسة فيها حالة المراجعة، وكل سطر بعده بند واحد.

| الحقل | المعنى |
|---|---|
| `id` | رمز البند: رمز القانون ثم رقم (`civil-code-01`، وبنود المذكرة الإيضاحية `civil-code-memo-01`) |
| `question` | سؤال بصيغة محامٍ، يُستعمل في تقييم المرحلة الرابعة |
| `query` | عبارة البحث التي يكتبها المختص؛ عليها يُقاس الاسترجاع |
| `law` | (اختياري) رمز القانون، ويوضع فقط إذا ذكر السؤال القانون صراحة |
| `expected` | المواد التي يجب أن يعيدها البحث: `{law, number, suffix}` |
| `expected_notes` | (اختياري، للقانون المدني) رقم ملاحظة المذكرة الإيضاحية التي تشرح المادة المتوقعة؛ لبند المذكرة مادة متوقعة واحدة |
| `notes` | موضع المواد في المصدر وسبب اختيارها |

## المراجعة

يراجع المحامي كل بند: هل السؤال واقعي، وهل عبارة البحث مما يكتبه مختص فعلًا دون نسخ من نص المادة، وهل المواد المتوقعة صحيحة وكافية للإجابة.
تُسجَّل الموافقة في الترويسة: `"review": {"status": "approved", "approved_by": "<الاسم>", "approved_on": "YYYY-MM-DD"}`.
أي تعديل على البنود يعيد الحالة إلى `draft` حتى يُراجع، ويُعاد بعده القياس على الصيغة الجديدة.

الفحص (من `services/legal-search`): `docker compose -f compose.test.yaml run --rm --build eval check`
