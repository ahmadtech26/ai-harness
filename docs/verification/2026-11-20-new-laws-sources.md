# New laws of 2026-11-20: where the registry values come from

The 12 laws added on 2026-11-20 (`review.status: draft`) were converted from an archive the owner supplied
(«14  11 24 القوانين الجديدة», received 2026-11-20). Each law file in it is a Markdown transcription that names
the PDF it was extracted from by SHA-256; those PDFs were not supplied. The files call themselves unverified
research transcriptions, not certified texts. No value below was checked against the Official Gazette or the
Legislation Bureau: each is what the archive file states, and the registry entry cites this note as its source
(`content/corpus/laws.json`, `sources`) until a lawyer replaces it with an official one.

The publication data is read from the publication note at the end of each file (anti-terrorism: from the
archive audit file); the converter removed that note from the law text. The full
conversion record, with every repair, is `.hq/docs/audits/2026-11-20-new-laws-conversion-log.md` in the
workspace.

## Added later the same day: the Chambers of Industry law and regulation

These two were not in the owner's archive. They were transcribed word for word on 2026-11-20 from scans of the
Official Gazette pages that the Jordan Chamber of Industry publishes on its website: a secondary source (images
of the Gazette pages), not the Gazette or the Legislation Bureau. Every page had a recorded second reading; the
transcription report is `.hq/docs/audits/2026-11-20-chambers-of-industry-transcription.md` in the workspace.
No scanned page shows the Gazette issue number or the publication date, so the registry entries carry no
`gazette` values; the dates below are the ones printed on the instruments (assent, Council of Ministers
decision), not publication dates. Nothing here was compared with the Gazette or the Bureau, and neither text
is known to be the text in force today.

Library text: each article exactly as transcribed (the transcription's words, spelling and hamzas, Eastern
Arabic digits and the printed «المادة N-» opening each article). Removed as not law text: the file header and
method notes, the issuance preamble, the HTML comments with page ranges, the `[ص N]` page markers (a page
break is not a paragraph break), the blockquote annotations, the `**` around printed sub-headings, the table
markup, the ministers' signature block, the uncertainty table and the notes after it. Each word the
transcription marks as uncertain («‹؟…؟›») is kept as plain text at the transcriber's best reading and listed
below with its page; a lawyer should check each against the Gazette before the text is quoted. The conversion
script checks that every article's words equal its source region's with only that markup removed
(`.hq/scratch/new-laws-convert/chambers.py`).
